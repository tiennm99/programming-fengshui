# programming-fengshui

Trang giới thiệu ảnh "Lựa chọn ngôn ngữ lập trình theo phong thuỷ".

## Chạy thử

Mở `index.html` trực tiếp trong trình duyệt, hoặc:

```bash
python3 -m http.server 8080
```

rồi truy cập http://localhost:8080.

## Cấu trúc

```
.
├── index.html
├── style.css
├── assets/

└── README.md
```
